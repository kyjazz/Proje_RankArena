# RankArena (Dinamik Quiz & Yarışma Platformu)

ASP.NET Core MVC mimarisi kullanılarak geliştirilmiş, kullanıcıların etkileşimli testler çözebildiği ve sıralamalara girebildiği dinamik bir yarışma platformudur.

## 🚀 Öne Çıkan Özellikler & Mimari

* **Kullanıcı Yönetimi:** Üyelik, oturum açma, yetkilendirme ve profil takibi altyapısı.
* **Dinamik Test Sistemi:** Farklı kategorilerde test/quiz oluşturma, çözme ve anlık sonuç görüntüleme imkanı.
* **Skor Tablosu (Leaderboard):** Kullanıcı skorlarına göre anlık sıralama ve rekabet mekanizması.

## 🛠️ Kullanılan Teknolojiler

* **Backend:** C#, ASP.NET Core MVC, Entity Framework Core
* **Veritabanı:** MSSQL
